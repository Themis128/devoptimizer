## 🆘 **TROUBLESHOOTING:**

### **❌ Script Won't Run:**
- Ensure you're running as Administrator
- Check Windows execution policy: `Set-ExecutionPolicy Bypass -Scope Process`
- Temporarily disable antivirus real-time protection

### **⚠️ Unexpected Behavior:**
- System restore points are created automatically
- Use Windows System Restore if needed: `rstrui.exe`
- Restart your computer after major optimizations

### **🔍 Get Help:**
- Check the detailed logs in `%TEMP%\dev-optimizer-[timestamp].log`
- Each tool provides comprehensive error messages and solutions
